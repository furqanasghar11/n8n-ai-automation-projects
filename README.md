# n8n-ai-automation-projects
A collection of practical AI Automation workflows built with n8n, OpenAI, APIs, Gmail, and Google Sheets.

These projects demonstrate how AI and workflow automation can be combined to automate repetitive business processes, process information, and generate structured results.
1. AI-Powered Email Lead Management & Classification

An AI-powered email automation workflow built with n8n, OpenAI, and Gmail.

What it does
Monitors incoming/unread emails
Extracts relevant sender information
Uses AI to understand and classify email requests
Categorizes emails based on their intent
Applies appropriate Gmail labels
Sends automated acknowledgement responses

2. AI-Powered Company Technology Research Automation

An AI automation workflow that analyzes company technology information using n8n, OpenAI, APIs, and Google Sheets.

What it does
Reads company information from Google Sheets
Retrieves technology information through an external API
Processes the returned technology data
Uses OpenAI to categorize technologies
Generates structured output
Updates the results back into Google Sheets
